# PKI Maturity Model 1.0.0 — Summary of changes

Initial release of the PKI Maturity Model.

## Overview

This is the first published release of the PKI Maturity Model. It establishes the framework used by subsequent releases: four maturity modules, a five-level maturity rubric, and the categories and requirements that assessors evaluate.

## What this release introduces

- **Four maturity modules** — Governance, Management, Operations, and Resources — covering the dimensions of PKI maturity.
- **Fifteen assessment categories** distributed across the modules: four each in Governance, Management, and Operations; three in Resources.
- **Five maturity levels** — Initial, Basic, Advanced, Managed, Optimized — applied uniformly to every category.
- **Detailed requirements** within each category, with guidance and sample assessment evidence.
